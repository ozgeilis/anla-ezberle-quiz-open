# Immutable historical banks

These are compatibility snapshots, not competing current banks. The original
v2–v71 modules were moved here with import-path changes only; v1 was already here.
Shared published/candidate/correction inputs remain one directory above. Keep
them until no supported historical record or export needs them.

The game registry uses v1–v70 here and the canonical `../questions-1500.ts` for v71.
The v71 composition here is used only by tooling/tests as a frozen reference.
See [the content boundary and update procedure](../README.md).
