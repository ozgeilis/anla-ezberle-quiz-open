Only the exterior white background was removed using the built-in image editing tool. The complete gold-framed compositions were retained, then optimized to maximum 640 pixels with their alpha channels. No UI labels are baked into these assets. `manifest.json` records the original supplied file hashes and the shipped derivative hashes/dimensions for traceability. Original supplied files are preserved outside the repository.

The women's scene represents a learning gathering; it is not an assertion of identifiable historical portraits. The life-of-the-Prophet scene is symbolic architecture, travel and books, not a depiction of the Prophet. All nine categories remain non-playable editorial previews. Tapping a preview opens an explanation only; it never selects or starts that category. Illustration approval is not question-bank publication or age-appropriateness approval.
