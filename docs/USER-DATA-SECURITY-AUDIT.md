# Son kullanıcı verisi güvenlik denetimi

Tarih: 23 Ekim 2026. Depo: `ozgeilis/anla-ezberle-quiz-open` (PRIVATE). Başlangıç: `8f5dc66aad2028db6ee08a6097ef798ab90ca8da`.

**Sonuç — kullanıcı verileri ve parolalar yönünden tam canlı ortam PUBLIC kabulü: DOĞRULANAMADI.** İncelenen kaynaklarda, Git geçmişinde ve test edilen erişim sınırlarında kullanıcı verisi/anahtar sızıntısı bulunmadı. Ancak geçmiş barındırma/Auth/SMTP loglarının tamamı incelenmedi; canlı sistemde oturum açarak iki hesaplı yazma testi de yapılmadı. Bu sınırlara rağmen tüm maddeleri PASS saymak doğru olmaz. PRIVATE durum korunur; bu rapor görünürlük veya üretim değişikliği onayı değildir.

## Yöntem ve sınırlar

- Frankfurt geliştirme projesi kimliği, adı ve `eu-central-1` bölgesi CLI ile doğrulandı. Canlı katalog sorguları `BEGIN TRANSACTION READ ONLY` içinde çalıştırıldı; `transaction_read_only=on` sonucu alındı. Yalnız izin/şema/fonksiyon metadata bilgileri okundu; canlı kullanıcı, e-posta, parola özeti, oturum veya oyun kayıtları dışarı aktarılmadı.
- Auth/API ayarları salt-okunur `supabase config diff` ile incelendi. Geçici yerel karşılaştırma dosyası yalnız politika sabitleri içerir; sunucuya uygulanmadı. SMTP kimlik bilgileri veya redirect token'ları rapora alınmadı.
- Dağıtımdaki Edge kaynak kodu salt-okunur indirildi ve başlangıç commit'iyle byte bazında eşleşti. Bu çalışmada Edge'de yalnız JWT yaşam süresi hakkındaki yorum açıklığa kavuşturuldu; çalışma mantığı veya dağıtım değiştirilmedi.
- Canlı HTTP sınır testlerinde yalnız anonim/geçersiz kimlikler kullanıldı. Yanıt gövdeleri okunmadan iptal edildi; beklenmeyen başarı olsa bile kullanıcı listesi rapora aktarılmayacak şekilde tasarlandı. İzin reddedilen RPC/Edge istekleri işlem gövdesine ulaşmadı.
- İki hesaplı gerçek Auth/Edge/PostgreSQL kabulü **yerel Supabase** üzerinde mevcut sentetik hesaplarla yapıldı. Ek SQL kimlikleri ve tüm sayaç/oyun fixture değişiklikleri tek transaction sonunda geri alındı. Yalnız testin açtığı yerel Auth oturumları kapatıldı; mevcut hesaplar silinmedi.
- Üretimde kullanıcı oluşturma/silme, giriş yapma, parola/e-posta gönderimi, migration, seed, RLS/izin, Auth veya Vercel ayarı değişikliği yapılmadı.

Yalnız `http://127.0.0.1:55431`, uygulama dışında tutulan açıkça seçilmiş fixture dosyaları, sentetik e-posta alanları ve sabit yerel Docker DB konteynerini kabul eder. - `tests/sql/user-data-security.sql`: RLS, rol izinleri, sahte actor, A/B bildirim ve Realtime ayrımı, özel maç/oda, public alan listesi ve doğrulanmamış hesap sınırlarını gerçek SQL ile test eder. Yerel koşucu işareti yoksa durur; transaction tüm fixture'ları geri alır.
- Edge'de yalnız yorum düzeltildi: JWT doğrulaması anlık evrensel logout iptali garantisi olarak anlatılmıyor. **Gözlenen bir kullanıcı verisi açığı bulunmadı; işlevsel sunucu değişikliği veya üretim düzeltmesi uygulanmadı.**
- `pnpm check`: soru bütünlüğü, TypeScript, lint ve 288 test başarılı; 0 hata/skip.
- Yeni Auth/Edge/RLS koşucusu: 12 grup başarılı. Mevcut sıralama SQL kabulü: 15 grup başarılı; tüm fixture'lar geri alındı. Canlı salt-okunur HTTP: 12 sınır kontrolü başarılı.
